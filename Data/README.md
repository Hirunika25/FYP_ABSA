
Research Data Access and Ethical Considerations

The raw review dataset collected from Daraz.lk is not publicly available in this repository due to ethical and privacy considerations. Access is restricted to authorized individuals for research purposes only.

The dataset is stored in Google Drive, and only individuals who have been granted permission can access it.

Raw Dataset (Restricted Access): https://drive.google.com/drive/folders/1Nv4UEqMuB6DG7PKx_AkP44UgqNpBKryQ?usp=sharing

The publicly available repository contains the research code and documentation, while access to the raw data is controlled to support responsible data handling and research ethics.
